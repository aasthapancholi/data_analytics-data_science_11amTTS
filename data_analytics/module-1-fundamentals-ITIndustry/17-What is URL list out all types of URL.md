# What is URL?

URL stands for Uniform Resource Locator.

It is the address used to locate a resource on the internet. A URL tells the browser where to find a webpage, image, file, or other online resource and how to access it.

Example:
- https://www.google.com
- https://www.example.com/about.html
- ftp://ftp.example.com/files/report.pdf

A URL usually has the following parts:

- protocol: tells the browser which communication method to use
- domain name: identifies the website or server
- path: shows the location of the file or page on the server
- query string: used to pass extra information
- fragment: points to a specific section inside a page

Example:
https://www.example.com/products?id=101#details

Here:
- https = protocol
- www.example.com = domain
- /products = path
- ?id=101 = query string
- #details = fragment

# Why URL is important

A URL is important because:
- it helps users access websites and resources
- it allows browsers to identify the exact page or file
- it supports navigation between pages
- it helps search engines understand website structure
- it enables link sharing and online communication

# Types of URL

## 1. Absolute URL

An absolute URL contains the complete address of a resource, including the protocol and domain name.

Example:
- https://www.google.com
- https://www.facebook.com/login

This type is used when we want the full path to a resource.

## 2. Relative URL

A relative URL is a short path relative to the current page or website.

Example:
- /about.html
- /products/laptops
- images/logo.png

This type is used inside a website because it is shorter and depends on the current location.

## 3. HTTP URL

An HTTP URL uses the HTTP protocol to access information on the web.

Example:
- http://example.com

HTTP is used for basic web communication, but it is not secure because data is not encrypted.

## 4. HTTPS URL

An HTTPS URL uses the secure version of HTTP.

Example:
- https://example.com
- https://www.amazon.in

HTTPS encrypts data between the browser and the server. It is commonly used for login pages, banking sites, and secure transactions.

## 5. FTP URL

FTP stands for File Transfer Protocol.

It is used to transfer files between computers over a network.

Example:
- ftp://ftp.example.com
- ftp://files.example.com/downloads

FTP is mostly used for uploading and downloading files.

## 6. Mailto URL

A mailto URL is used to open an email program or create a new email message.

Example:
- mailto:info@example.com

It helps users send an email directly by clicking a link.

## 7. Tel URL

A tel URL is used to open a phone dialer or call a phone number.

Example:
- tel:+919876543210

It is useful in websites and mobile applications for contact or support links.

## 8. File URL

A file URL points to a local file on a computer or local system.

Example:
- file:///C:/Users/Name/Documents/report.pdf

This type is used mainly for local file access rather than internet browsing.

## 9. Data URL

A data URL stores data directly in the URL itself instead of referencing a separate file.

Example:
- data:text/plain;base64,SGVsbG8gV29ybGQ=

It is mostly used for small embedded resources like icons, scripts, or small images.

## 10. JavaScript URL

A JavaScript URL executes JavaScript code when the link is clicked.

Example:
- javascript:void(0)

This type is rarely used in modern web development because it can create security and usability problems.

## 11. Domain-based URL

A URL may be based on a domain name like:
- https://www.google.com
- https://www.linkedin.com
- https://www.youtube.com

This is the most common URL type used on the web.

## 12. Subdomain URL

A subdomain is a separate section of a website and appears before the main domain.

Example:
- https://blog.example.com
- https://admin.example.com
- https://shop.example.com

Subdomains are used to organize different parts of the same business or website.

## 13. Static URL

A static URL does not change often and is usually simple and readable.

Example:
- https://example.com/about
- https://example.com/contact

These are easy to remember and are helpful for SEO.

## 14. Dynamic URL

A dynamic URL contains parameters and may change based on user input or database values.

Example:
- https://example.com/products?id=10&category=books
- https://example.com/search?q=analytics

Dynamic URLs are commonly generated by websites and applications.

## 15. Canonical URL

A canonical URL is the preferred version of a page when there are multiple URLs that show the same content.

Example:
- https://example.com/products/laptop

This helps avoid duplicate content issues in SEO.

## 16. URL with query parameters

A URL can include query strings to send data to the server.

Example:
- https://example.com/search?name=python
- https://example.com/products?category=electronics

These are useful for filtering, searching, or passing information.

## 17. URL with fragment

A fragment is a part of the URL after # and is used to go to a specific section of a page.

Example:
- https://example.com/guide#chapter2

This helps users jump directly to a certain section in a document.

# URL structure in detail

A typical URL looks like this:

scheme://hostname:port/path?query#fragment

Example:
https://www.example.com:443/products?id=5#details

Breakdown:
- scheme: https
- hostname: www.example.com
- port: 443
- path: /products
- query: ?id=5
- fragment: #details

# Difference between URL and URI

A URL is a type of URI.

- URI: Uniform Resource Identifier; a unique identifier for a resource
- URL: Uniform Resource Locator; a location that tells where a resource is

Example:
- URI: a user profile identifier
- URL: the web address of the user profile page

# Summary

A URL is the web address used to locate and access a resource on the internet.

It can be absolute or relative, and it may use different protocols such as HTTP, HTTPS, FTP, mailto, tel, or file.

Important URL types include absolute URL, relative URL, dynamic URL, static URL, query URL, fragment URL, domain URL, and subdomain URL.

# Final thought

URLs are the foundation of the web. Without URLs, users and systems would not know where to find pages, files, or services online. Learning different URL types helps us better understand how websites work, how data is exchanged, and how the internet connects people, applications, and information.
