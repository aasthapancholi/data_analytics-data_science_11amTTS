# What is data?

Data is a collection of facts, information, observations, or details that can be recorded and analyzed. It can be in the form of numbers, text, images, audio, video, or any other digital content.

In simple words, data is the raw material used to create information and knowledge.

Examples of data:
- Student marks
- Customer names and emails
- Sales numbers
- Product reviews
- Temperature readings

# Why is data important?

Data is important because it helps us:
- understand patterns and trends
- make better business decisions
- improve products and services
- track performance
- predict future outcomes

# Types of data

Data can be classified into different types depending on its structure and format.

1. Structured data
2. Semi-structured data
3. Unstructured data
4. Raw data

# 1. Structured data

Structured data is data that is organized in a predefined format, usually in rows and columns. It is easy to store, search, and analyze.

It is commonly stored in:
- Excel files
- CSV files
- SQL databases
- Tables

Example:

| id | name | email | phone |
|----|------|-------|-------|
| 1  | Mansi | mansi@gmail.com | 9876543210 |
| 2  | Rahul | rahul@gmail.com | 9123456780 |

Features of structured data:
- well-organized
- easy to process
- stored in tables or rows/columns
- suitable for analytics and reporting

# 2. Semi-structured data

Semi-structured data is not fully structured like a table, but it has some organization such as tags, labels, or keys.

It is often stored in:
- JSON files
- XML files
- APIs

Example of JSON data:

```json
{
  "id": 1,
  "name": "Mansi",
  "email": "mansi@gmail.com",
  "phone": "9876543210"
}
```

Features of semi-structured data:
- has some internal structure
- easier than unstructured data
- often used in web applications and APIs

# 3. Unstructured data

Unstructured data is data that does not follow a fixed format or predefined structure. It is difficult to store and analyze with traditional tables.

Examples:
- images
- videos
- audio files
- WhatsApp chats
- social media posts
- emails
- PDFs

Features of unstructured data:
- no fixed row/column format
- more difficult to analyze
- often requires AI, NLP, or text processing

# 4. Raw data

Raw data is data collected directly from a source before cleaning, processing, or organizing it. It is not yet ready for analysis.

It may contain:
- duplicates
- missing values
- spelling mistakes
- incorrect entries
- irrelevant information

Example of raw data:

```json
[
  {"id": 1, "name": "Mansi", "email": "mansi@@gmail.com"},
  {"id": 2, "name": "Rahul", "email": "rahul@gmail.com"},
  {"id": 3, "name": "", "email": "anil@gmail.com"}
]
```

This raw data needs cleaning before it can be used for analysis.

# Data architecture

Data architecture describes how data is collected, stored, processed, and used in a system.

A simple architecture flow is:

```text
Data Source --> Data Collection --> Data Storage --> Data Processing --> Data Analysis --> Data Visualization --> Decision Making
```

# How is data used in data analytics?

Data analytics is the process of examining data to find useful patterns, trends, and insights.

Data is used in analytics in the following ways:

1. Collection
   - Data is collected from websites, forms, databases, apps, sensors, and social media.

2. Cleaning
   - Data is cleaned to remove errors, duplicates, and incomplete values.

3. Storage
   - Data is stored in databases, cloud storage, Excel sheets, or data warehouses.

4. Processing
   - Data is transformed and organized for analysis.

5. Analysis
   - Data is examined using statistics, SQL, Python, Excel, or BI tools.

6. Visualization
   - Results are shown using charts, dashboards, and reports.

7. Decision making
   - Businesses use insights to improve strategy, marketing, sales, and performance.

# Example of data analysis

Suppose a company records daily sales data:

| Date | Product | Quantity | Sales |
|------|---------|----------|-------|
| 01-01 | Shoes | 20 | 2000 |
| 02-01 | Shoes | 30 | 3000 |
| 03-01 | Bags | 25 | 2500 |

By analyzing this data, the company can answer:
- Which product sells the most?
- Which month has highest sales?
- Which product should be promoted more?

# Summary

- Data is a collection of facts and information.
- Data can be structured, semi-structured, unstructured, or raw.
- Structured data is easiest to analyze.
- Raw data must be cleaned before use.
- Data analytics helps us convert raw data into meaningful insights and smart decisions.

# Final thought

Data is the foundation of data analytics. Without data, there are no patterns, insights, or decisions. In every field such as business, healthcare, education, banking, and marketing, data plays an important role in improving performance and making informed choices.
