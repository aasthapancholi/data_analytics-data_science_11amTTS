# Aastha Pancholi - Data Analytics Portfolio (Freshers Edition)

A high-performance, fully responsive **Data Analytics Portfolio** tailored specifically for **freshers and entry-level data analysts**, engineered with **Tailwind CSS v4** and vanilla JavaScript without external heavyweight frontend frameworks.

---

## 🌟 Portfolio Overview & Highlights

- **Target Persona:** Entry-Level / Fresher Data Analyst (Aastha Pancholi)
- **Styling Engine:** **Tailwind CSS v4** (Modern `@theme` variables, zero-runtime overhead)
- **Mobile Navigation:** **Right-Slide-In Off-Canvas Drawer** with hamburger toggle button, dark backdrop overlay, and keyboard accessibility (`Escape` key close).
- **Core Focus:** Turning raw data into business intelligence, KPI tracking, automated workflows, and decision support models.

## 🚀 How to Open and View the Portfolio

### Method 1: Direct File Preview
Double-click [`index.html`](file:///c:/data_analytics_data_science_11am_tts/data_analytics/module-1-fundamentals-ITIndustry/index.html) or open it in your default web browser (Chrome, Edge, Firefox, Brave):
```text
file:///c:/data_analytics_data_science_11am_tts/data_analytics/module-1-fundamentals-ITIndustry/index.html
```

### Method 2: Local Python Web Server
Open PowerShell in this directory and run:
```powershell
python -m http.server 8000
```
Then navigate to:
```text
http://localhost:8000/index.html
```

### Method 3: Mobile View Testing
1. Open the page in Google Chrome.
2. Press `F12` (or right-click and choose **Inspect**).
3. Click the **Toggle Device Toolbar** icon (or press `Ctrl + Shift + M`).
4. Select a mobile device (e.g. *iPhone 14*, *Pixel 7*, or *Samsung Galaxy S20*).
5. Click the **Hamburger menu icon** in the top-right corner to see the smooth right-side slide-in navigation drawer.

## 📸 How to Add or Change Your Profile Photo

The website is already pre-configured to look for your photo named **`profile.jpg`** in the project folder with built-in styling, rounded borders, glowing rings, and automatic fallback badges (`AP`).

### Step 1: Copy Your Photo into the Directory
Place your portrait photo into this exact folder:
```text
c:\data_analytics_data_science_11am_tts\data_analytics\module-1-fundamentals-ITIndustry\
```

### Step 2: Name the Image File
Rename your photo file to:
```text
profile.jpg
```
*(Or if it is a PNG, name it `profile.png` and update `src="profile.png"` in `index.html`).*

### Where Your Photo Will Automatically Appear:
1. **Hero Section:** Next to the availability badge.
2. **About Me Section:** Featured large portrait card with status indicator and glowing shadow.
3. **Navbar Header:** Next to your name.
4. **Mobile Navigation Drawer:** Top header inside the slide-in drawer.
