# What is Excel?

Microsoft Excel is a spreadsheet program developed by Microsoft. It is used to organize, calculate, analyze, and visualize data in a tabular format.

Excel is one of the most commonly used tools in business, finance, data analysis, accounting, and reporting.

# Why is Excel used?

Excel is used because it allows users to:
- store large amounts of data
- perform calculations
- create reports
- analyze trends and patterns
- build dashboards
- create charts and graphs
- manage budgets and records

# What is a workbook in Excel?

A workbook is the main file in Excel.

It is a single file that contains one or more worksheets.

When you open Excel, you create or open a workbook.

A workbook is like a notebook containing multiple pages.

# What is a worksheet in Excel?

A worksheet is a single tab within a workbook.

It is where you enter data in rows and columns.

Each worksheet is like one page of the workbook.

A workbook can contain multiple worksheets such as:
- Sheet1
- Sheet2
- Sheet3

# Structure of Excel

Excel is made of:
- rows
- columns
- cells
- worksheets
- workbook

Rows are numbered horizontally.
Columns are labeled alphabetically.
A cell is the intersection of a row and a column.

Example:
- A1
- B5
- C10

# How to create a workbook in Excel

To create a new workbook in Excel:

1. Open Microsoft Excel.
2. Click on Blank Workbook.
3. A new workbook opens with a default sheet.
4. You can save it using File > Save As.

You can also use:
- Ctrl + N to create a new workbook

# How to save a workbook

To save a workbook:

1. Click the File tab.
2. Select Save As.
3. Choose the folder location.
4. Enter the file name.
5. Click Save.

# How to create a new sheet in Excel

To create a new worksheet in an Excel workbook:

1. Open the workbook.
2. Click on the + button next to the existing worksheet tab.
3. A new sheet is created.
4. Rename the sheet by double-clicking the tab name.

You can also use:
- Shift + F11 to insert a new worksheet

# How to rename a worksheet

To rename a sheet:

1. Right-click the worksheet tab.
2. Select Rename.
3. Type the new name.
4. Press Enter.

Example sheet names:
- Sales
- HR
- Data
- Summary

# How to delete a worksheet

To delete a worksheet:

1. Right-click the sheet tab.
2. Choose Delete.
3. Confirm the deletion.

# How to move or copy a worksheet

To move or copy a sheet:

1. Right-click the sheet tab.
2. Select Move or Copy.
3. Choose the target location.
4. Click OK.
