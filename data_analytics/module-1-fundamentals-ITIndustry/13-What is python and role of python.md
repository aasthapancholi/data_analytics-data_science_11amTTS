# What is Python?

Python is a high-level, easy-to-learn programming language created by Guido van Rossum.

It was first released in 1991 and has become one of the most popular programming languages in the world.

Python is widely used for web development, automation, data analysis, data science, machine learning, artificial intelligence, and scripting.

# Why is Python popular?

Python is popular because:
- it is simple and readable
- it has a clean syntax
- it supports many libraries and frameworks
- it is suitable for beginners and professionals
- it is used across many industries

# Features of Python

Some important features of Python are:
- easy to learn
- open source
- cross-platform
- object-oriented language
- supports large libraries
- good for automation and analytics

# Role of Python in data analytics

Python is one of the most important tools in data analytics.

It helps data analysts and data scientists to:
- collect data
- clean and transform data
- analyze large datasets
- perform statistical calculations
- create visualizations
- build dashboards
- automate repetitive tasks

# Why Python is used in data analytics

Python is used in analytics because it provides powerful libraries such as:
- Pandas for data manipulation
- NumPy for numerical computations
- Matplotlib for visualizations
- Seaborn for statistical charts
- SciPy for scientific computing
- Scikit-learn for machine learning
- SQLAlchemy for database connectivity

# Example use of Python in data analytics

A data analyst can use Python to read a CSV file, clean the dataset, and create visual charts.

Example:

```python
import pandas as pd

df = pd.read_csv("sales.csv")
print(df.head())
```

This shows how Python can load and view data quickly.

Python is more powerful than Excel for large data processing.

- automation

# Advantages of Python

- simple syntax
- fast to learn
- large community support
- many libraries
- suitable for data science and analytics

# Disadvantages of Python

- slower than some compiled languages
- not ideal for very heavy desktop applications
- memory usage can be high in some tasks
